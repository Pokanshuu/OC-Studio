## A. 会出错的（数据层）

### A1. 存反向 —— 唯一一处真会漂的地方

`country.characters` / `country.events` 是存在**国家自己行里**的数组，靠 `src/lib/membership.ts` 在保存那一刻跟角色 / 事件双边写。

证据：`useCountryForm.ts` 读 `country.characters ?? []`、保存 `characters: editableCharIds`。

| 漂移场景 | 结果 |
|---|---|
| 在 Obsidian 里改角色的 `国籍` | 国家的 `所属角色` 还是旧的，刷新也不变 |
| 导入 `.ocbak` | membership 不参与，两边各按文件来 |
| 软删除一个角色 | 国家页还挂着他 |
| 老数据迁移 | 只在有字段时补，缺的不会推 |

**修法**：阶段二·一 —— 国家页改查询（`filter(c => c.countryId === id)`），`membership.ts` 退役，盘上旧数组**不读、不写、不删**（零迁移）。

### A2. 关系只能连角色

`character.relatedCharacters` 是唯一的关系存储。国家之间（盟友 / 敌对）、角色与国家（使节）、事件之间（导致）都没有字段，只能写进正文——而正文里的东西，关系图和时间线都看不见。

**修法**：阶段二·二 —— 显式边 `关系: [{ 类型, 目标, 名称 }]`。

### A3. 同一个事实三种写法

角色国籍是 `countryId`（单值），事件的国家是 `countries[]`（多值），国家侧又各有一份镜像数组。同一个概念三种形状，每处单独处理。

**修法**：同 A2 —— 统一成"实体侧单写 + 反向查询"。

## B. 看不出来的（展示层）

### B1. 时间线的泳道是空的

`assignLanes` 只是把重叠事件摞起来避免遮挡，行不表达任何语义。事件之间的 `relations` 数据存在，但轴上一条线都不画；多角色事件无法表达"这件事把谁卷进来了"。

**归属**：`docs/时间线.md`（参与者轨道 + 事件连线）

### B2. 关系图不可复现、节点同形

力导向每次重算位置，导出 / 静态站 / 换台机器都不是同一张图；所有类型节点长得一样（图标 + 名字的小团）；移动端拖不动。

**归属**：`docs/关系图.md`（静态手摆 + 节点形态）

### B3. 同一个东西两个名字、两种形态

角色编辑器叫「关系」用表格，事件 / 国家叫「关联」用 chips，导航叫「关系图」。

**归属**：`docs/模板.md` §6.3 + §10 术语收口

## C. 会越写越重的（结构层）

### C1. 四类实体各写一遍编辑器和保存管线

加一类新实体 = 再写一遍编辑器；改一处布局 = 改四处。四个 `use<X>Form` 各自维护脏标记、保存、派生。

**归属**：`docs/模板.md` 阶段一（组件 registry + 渲染循环）

### C2. 标签没有自己的位置

角色里是字段行，事件 / 国家里挂在「关联」下面，数据层又是独立的一张表。

**归属**：`docs/模板.md` §6.4 + §8.8（独立组件 + 维度管理）

### C3. 隐藏的字段被当成正文露在编辑界面

「已隐藏：元素 全部显示」那一行。**已修**（`012d4dc`）。

## D. 根因只有两条

1. **没有"数据 vs 展示"这条线** —— 所以"反向列表"被当成数据存了下来（A1）。已写成 `docs/模板.md` §1.4。
2. **"一类实体一套编辑器"** —— 所以展示逻辑被复制了四遍（C1），连带 B1、B3。

其余都是这两条的下游。
