# 主题

> 现状是**两套固定的令牌（亮 / 暗）**，这份文档记的是"允许用户改令牌"的方向与边界。未实现。

---

## 0. 一句话

主题 = **一组被允许修改的界面令牌**，不是一个能写任意 CSS 的模板。

---

## 1. 范围

### 1.1 开放（安全令牌）

`--oc-paper` / `--oc-paper-alt` / `--oc-paper-card` / `--oc-line` / `--oc-line-hover` / `--oc-ink` / `--oc-ink-muted` / `--oc-ink-faint` / `--oc-hover` / `--oc-scrim` / `--oc-danger`

再加上：

- **背景图**（带明暗两套可读性遮罩）
- **强调色**（见 §2，需要先定适用范围）

### 1.2 不开放

- 任意 CSS / JS
- 圆角、边框宽度、阴影层级、间距（这些是设计系统的骨架，不是皮肤）
- 字体族（衬线只给标题，这条是身份）

---

## 2. 强调色是新增项，不是现成的

现在全站以**墨色**为主，"选中"是浅底块，"强调"是墨色本身。要加 `--oc-accent` 必须先回答：它出现在哪？

| 候选 | 风险 |
|---|---|
| 链接 / `[[内链]]` | 低，但会跟"墨色下划线"的页签语言打架 |
| 选中态 | 高，等于把"选中 = 浅底块"改掉 |
| 主按钮 | 高，现在主按钮是浅底实心，加彩色会破坏"一屏不该有第二块深色" |
| 图表 / 时间线 / 关系图 | 低，这一类本来就允许有颜色 |

**倾向**：只在图表与时间线里开放强调色，界面控件不开放。这条要单独拍板。

---

## 3. 主题包

```
theme.json
├─ id / name / author / version
├─ tokens:  { paper, ink, line, ... }
├─ background: { image, mode: cover|tile, scrim: light|dark }
└─ preview.png
```

- 导入时校验：颜色格式、对比度阈值、资源大小、版本
- 一键预览 / 应用 / 恢复默认
- 内置亮 / 暗两套是保底，不可删

---

## 4. 与模板的关系

- 模板只能存**主题 id**（`docs/模板.md` §8.7），不能内联令牌值
- 「不同国家的角色用不同背景」= 两个模板各挂一个主题 id
- 世界级覆盖（整个库换主题）后置，先做应用级

---

## 5. 前置与风险

**前置**：`globals.css` 的令牌体系（已有）、`settings.tsx` 的主题切换（已有）。**不依赖模板功能**，可以独立做。

| 风险 | 说明 |
|---|---|
| 对比度 / 可读性 | 社区主题最常见的翻车点，导入时必须算对比度 |
| 安全 | 禁止任意 CSS/JS，只能填值 |
| Mica / 安全区 | 外壳是透明的（Mica），主题不能把外壳铺成实色 |
| 版本兼容 | 令牌增删要让旧主题降级而不是崩 |
