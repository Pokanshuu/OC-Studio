# 标题衬线字体（思源宋体子集）

**已打包（2026-11-15）**：`public/fonts/oc-serif.woff2`，单文件可变字重，**1.35 MB**。
`globals.css` 里一条 `@font-face 'OC Serif'`（`font-weight: 200 900`、`font-display: swap`），
`--font-serif` 首位就是它。文件随仓库走，Tauri 打包时 `frontendDist: "../out"` 会把
`out/fonts/` 一起塞进安装包，不需要额外配置。

## 为什么

`--font-serif` 从 v0.20.5 起是 `'OC Serif', 'Noto Serif SC', 'Source Han Serif SC', 'Songti SC', serif`。
大多数 Windows 机器没装思源宋体，标题会落到系统宋体（SimSun）—— 小字号下发虚、笔画细，
一条 `@font-face` 就能把这个气质问题解决掉。

## 文件怎么来的

1. **源字体**：[Noto Serif SC](https://github.com/notofonts/noto-cjk/releases)（SIL OFL 1.1，
   版本 `Serif2.003`）的可变字重包 `02_NotoSerifCJK-OTF-VF.zip` →
   `Variable/OTF/Subset/NotoSerifSC-VF.otf`（21.6 MB，`wght` 轴 200–900）。
   下载物放在仓库外的临时目录，不进仓库。
2. **字表** `scripts/fonts/charset.txt`（4720 字符，由 `scripts/fonts/make-charset.py` 生成，已提交）：
   - **GB2312 一级汉字 3755 字**（`0xB0A1–0xD7F9`）—— 常用字覆盖口径。
     《通用规范汉字表》一级字表（3500 字）的电子文本在本机离线拿不到（GitHub raw / 维基文库都连不上），
     所以用了等价口径里更全的一档：3755 字是 3500 字表的近似**超集**，多出来的都是常用字，
     只会多不少。要换成真正的 3500 字表，只改 `charset.txt` 再跑一次 `subset.sh` 即可。
   - GB2312 符号区 `0xA1A1–0xA9FE`（全角标点 / 数字 / 量词符号）
   - ASCII `U+0020–007E`、CJK 标点 `U+3000–303F`、全角区 `U+FF00–FFEF`、
     另外补了不在上述区段里的 `—`、`…`、`·`
   - 字体里实际命中 **4706 个字形**（其余 14 个是字表里字体本身没有的码位）
3. **子集化** `scripts/fonts/subset.sh`（可重跑）：

   ```bash
   # 依赖：python + fonttools + brotli
   python -m pip install fonttools brotli
   # Git Bash / WSL 里跑（Windows 上没有 python3 别名时加 PYTHON=python）
   PYTHON=python bash scripts/fonts/subset.sh "D:/.../Variable/OTF/Subset/NotoSerifSC-VF.otf" public/fonts
   ```

   脚本产出 `public/fonts/oc-serif.woff2` 并检查总体积 ≤ 2.5 MB（超了直接失败，不自动砍字表）。

## 为什么是一个可变文件而不是两档静态档

两种都做了，量了体积，取小的：

| 方案 | 文件 | 体积 |
|---|---|---|
| 静态 SemiBold + Bold 各一份 | `oc-serif-600.woff2` + `oc-serif-700.woff2` | 2.20 MB |
| **可变字重单文件（采用）** | `oc-serif.woff2`（wght 200–900） | **1.35 MB** |

顺带解决了静态两档的副作用：`@font-face` 只声明 600–700 时，`.tiptap h1`（400）和 `h3`（500）
会按 CSS 字体匹配规则落到最近的 600，正文标题会莫名变粗（没有字体文件时看不出来）。
可变文件把 200–900 全声明出来，400 / 500 就是真字重。

## 注意

- `font-display: swap`：字体没加载完先用系统衬线，不阻塞首屏。
- 字重只到 200–900；`--font-serif` 现在只用于 400 / 500 / 600 / 700 四处，都在轴内。
- 正文（`text-reading`）默认**不是**衬线；如果以后要整篇衬线排版，同一份可变文件够用，改字体栈即可。
- 子集里没有的字会回落 `--font-serif` 后面的系统字体（不会显示豆腐块，只是字形不统一）。
