# 标题衬线字体（思源宋体子集）

仓库里**不带字体文件**：体积该由作者决定。放进去就生效，不放就回落系统衬线。

## 为什么

`--font-serif` 从 v0.20.5 起是 `'OC Serif', 'Noto Serif SC', 'Source Han Serif SC', 'Songti SC', serif`。
大多数 Windows 机器没装思源宋体，标题会落到系统宋体（SimSun）—— 小字号下发虚、笔画细，
一条 `@font-face` 就能把这个气质问题解决掉。

## 怎么做

1. 下载思源宋体（Noto Serif SC / Source Han Serif SC），取 **SemiBold 600** 与 **Bold 700** 两档：
   <https://github.com/notofonts/noto-cjk/releases>（`NotoSerifSC-SemiBold.otf` / `NotoSerifSC-Bold.otf`）
2. 子集化（`pip install fonttools brotli`）：常用 3500 字 + 标点，两档各出一份 woff2：
   ```bash
   pyftsubset NotoSerifSC-SemiBold.otf \
     --text-file=<常用字表.txt> \
     --unicodes="U+0020-007E,U+3000-303F,U+FF00-FFEF" \
     --flavor=woff2 --output-file=oc-serif-600.woff2
   ```
   3500 字 + 标点的 woff2 大约 1–2 MB。
3. 两档合成一个可变字重文件（可选）：`fonttools varLib.merger`，或直接只用 700 一档。
   最终文件名固定为 `public/fonts/oc-serif.woff2` —— `globals.css` 的 `@font-face` 指向它，
   `font-weight: 600 700`。
4. 放好后跑 `npm run build` 确认构建通过；文件不存在时浏览器静默跳过这条 `@font-face`。

## 注意

- `font-display: swap`：字体没加载完先用系统衬线，不阻塞首屏。
- 正文（`text-reading`）如果也要用衬线，另加一档 400 字重，并把 `--font-serif` 的 400 也指过来。
