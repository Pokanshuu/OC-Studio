# 地图

> 定位：地图是**一个视图**（跟时间线、关系图平级），不是一类新实体。

---

## 0. 一句话

**地图不是数据，是看数据的一个角度**——跟时间线把事件摆到时间轴上一样，地图把地点摆到平面上。

---

## 1. 两种地图，别混

| | 手绘地图 | 生成地图 |
|---|---|---|
| 长什么样 | 一张背景图（作者画好的大陆/城市） | 算法生成的轮廓 |
| 数据 | 背景图 + **锚点** | 从参数与种子推导 + 可调参数 |
| 作者投入 | 高（得先有图） | 低（一键出草图） |
| 定位 | **主战场**：最终展示用 | **起步工具**：没图时先有个大概 |

生成器是**官方插件**（`src/plugins/map-generator/`，见 `docs/插件.md` §0.1.1），手绘地图是**内置视图**（`src/features/map/`）。

- 内置侧只认「底图 + 锚点 + 图层」，**不含任何生成算法**；插件被禁用或移除时，手绘地图照常工作
- 插件产出的只是**底图**，锚点仍然必须落在实体上——否则数据和插件绑死（§7 风险 4）
- 插件没有数据权限：不读 Dexie、不写文件，宿主把参数喂给它、把像素接回来

---

## 2. 数据：锚点存在实体上

| 键 | 在哪 | 说明 |
|---|---|---|
| `map_position: { x, y }` | 实体的 frontmatter | 归一化坐标（0–1），与图片尺寸无关——换一张更清晰的地图不用重摆 |
| `map_id` | 实体（可选） | 一个库可以有多张地图（世界 / 某国 / 某城），为空 = 主地图 |

地图自身（`category: 地图` 的笔记）另有五格：`map_image` / `map_width` / `map_height`（底图路径与像素尺寸）、`map_seed` + `map_params`（生成快照）、`map_mode`（当前视图）、`map_annotations`（政治标注）。

**点归实体，线归地图**：国家 / 事件 / 词条 / 城市都是**锚点**（在实体自己的 frontmatter 上，点一下能跳过去）；国界多边形与道路折线没有实体可寄放，才存成地图笔记上的 `map_annotations`（JSON 字符串，坐标同样归一化 0–1）。标注不欠任何笔记，删一条不影响实体。

**`map_mode` 与 `map_image` 是一对**：切视图只改这两个键，`map_seed` / `map_params` 一个字节都不动 —— 快照才是可重画一档图的真源，所以一来一回永远得到同一张图，也不用为每档各存一份参数。手传的底图这两格都是空的，界面据此**不显示视图条**。

背景图存 `.ocstudio/maps/<名>.png`，随库走。

**为什么归一化**：`graphPosition` 是绝对坐标，因为关系图没有底图；地图有底图，底图会换（草图 → 精修），绝对坐标会全废。

---

## 3. 与实体的联动

| 方向 | 行为 |
|---|---|
| 实体 → 地图 | 「地点」组件里出现「在地图中查看」；有锚点就定位过去 |
| 地图 → 实体 | 点锚点 = 跳转那个国家 / 事件 / 词条 |
| 地点字段 | 现在是一行文本（`place`），**锚点存在实体上而不是地点字段里**——地点是给读者看的名字，锚点是给地图用的坐标 |

事件也可以有锚点（"这里发生过什么"），所以地图上能叠一层事件图层。这是它比"插入一张图片"多出来的全部价值。

---

## 4. 交互（第一版只做这些）

- 缩放 / 平移（与关系图同一套手势与 `MIN_ZOOM`）
- 点锚点 → 打开实体
- 拖动锚点 → 改位置（**写回实体 frontmatter**；移动端只读）
- 图层开关：国家 / 事件 / 词条（对应实体类型）
- **不做**：路径规划、距离测量、经纬度投影、多层地形——那是 GIS，不是设定集

---

## 5. 与模板的关系

地图可以作为一个 **block 组件**塞进模板（比如国家页显示"本国位置"的缩略）。缩略态只读、不可拖。

---

## 6. 不做

- 真 GIS（投影 / 经纬度 / 等高线）
- 在应用里画地图（画图是外部工具的事，我们只认一张背景图 + 锚点）
- 地图之间互相嵌套的层级导航（先只有"一个库多张图"）

---

## 7. 风险

| 风险 | 说明 |
|---|---|
| 底图换了，锚点全歪 | 归一化坐标能扛"换分辨率"，扛不住"构图改了"——换了构图就该重摆，UI 要提示这一点 |
| 大底图性能 | 与主题背景图同一个问题：上屏用压缩版，原图只在导出时用 |
| 锚点重叠 | 两个国家挨得近时锚点会叠，需要错开或聚合（与关系图同一套问题） |
| 生成器的产出算谁的 | 插件生成的地图只是"底图"，锚点仍然必须落在实体上，否则数据和插件绑死 |

## 10. 2026-11-06 改版（四个角 + 一条控制条）

口径：**地图是一整块画布，控件只出现在四个角**，每个角只回答一个问题；
底部中轴只留一条控制条。没有页头、没有卡片边框。`MapView` 整块铺满内容区（`MapCanvas` 的 `bleed`）。

| 位置 | 回答的问题 | 定法 |
|---|---|---|
| 左上 | 我在看哪张图 | 地图名片（名字 + ⌄ + 锚点数），点开是**天气 App 式的卡片列表**（`MapSwitcher`）—— 左边名字压在纸色实底、向右渐隐到缩略图（一道纯 `from-paper` 渐变，**不用 backdrop-blur + mask** —— 遮罩一旦没生成，模糊层会铺满整行，名字底下糊出一块灰带）；面板用不透明的 `PANEL_SOLID`（它压在地图上，85% 底会把底图透上来）。行内给**锚点数**（不再写「有底图 / 无底图」），当前行的重命名 / 删除压右上，底部是「新建地图 / 详情」。**这是唯一的地图切换入口**，点外部或 Esc 收起 |
| 右上 | 模式与输出 | 一条浮条（`FLOAT_BAR`）：全屏 / 编辑 / ⋯。编辑是**唯一模式开关**，进编辑后就地变「完成」（入口与出口同处）；⋯ 收低频动作：导出图片 / 设置或更换底图 / 移除底图 / 生成地图 / 地图详情。条目在**点开时**才构建（不在渲染期拼闭包） |
| 底部中轴 | 我在看什么 | **控制条**（`MapControlBar`）：左端「图层」按钮 + 六档底图（`terrain / contour / temperature / moisture / biome / political`）。**手绘底图没有六档，这一段整段不渲染**，整条缩成一枚按钮 |
| 右下 | 我能改什么 | 编辑态才出「标记（加锚点）」与「标注（画国界 / 画道路 / 取剖面）」；下面常驻缩放条（− 100% + ⟲），视口状态提到 `MapView` 持有，浮层与画布共用一个 |
| 图层面板 | 显示 + 图例 | 「图层」按钮上方展开：三个图层勾选 + 当前档位的图例（`MapLegend`）。**图例只在这里**，不再单独浮一块 —— 手绘底图没有色阶，图例也就不出现 |

两种地图按能力裁剪（界面不套同一套控件）：

| | 导入 / 手绘底图 | 生成地图 |
|---|:--:|:--:|
| 六档底图 + 图例 | — | ✓ |
| 重新生成 / 调参 | — | ✓ |
| 设置 / 更换 / 移除底图 | ✓ | —（重新生成即可） |
| 锚点 / 国界 / 道路 / 导出 | ✓ | ✓ |

其余定法：

| 项 | 定法 |
|---|---|
| 查看 / 编辑 | **默认查看态**（`oc-map-mode`，记住上次）：能缩放平移、点锚点跳实体；锚点不可拖。查看态右键锚点**只给「打开」**，移除锚点只在编辑态出现 |
| 地图详情 | `MapDetailDialog`（380 宽，**单列**）：名字（铅笔就地改名）/ `seed` / 尺寸 / 类型 / 锚点 / 标注（字段行两列）+ 四个动作：**编辑地图**（关掉弹窗进编辑态）、**在生成器中重新生成**（带着 `map_seed` + `map_params` 打开生成器，调参后仍是同一片大陆）、**导出 PNG / JPG**（只带属于这张图的锚点）、**导出地图包**（`.ocmap`）；底部删除（`AlertDialog` 确认，库里只剩一张时不给删）。**不做左清单**：切换地图走左上名片，两栏在窄窗口下会把右栏挤到折线下面（就是「只看到一串地图名」）。入口两处：左上名片 ›「详情」、右上 ⋯ ›「地图详情」 |
| 生成器入口 | **没有底图时**，画布正中的空态卡给两个出口：「生成地图」（主）/「导入底图」（次）—— 这是两种地图分岔的地方。有底图后走右上 ⋯ ›「生成地图」 |
| 生成器版式 | **左栏 300 + 预览**（`MapGeneratorPanel`）。左栏是「形态 / 参数」两组字段行，**生成**钉在栏底；右栏自上而下是**视图**（六个文字档位，选中浅底块，未生成时禁用）→ **预览**（生成前是一张空态卡「还没有生成底图 / 生成地图」，不是一块空画布）→ **图例卡**（压在画布右上，内容是 `MapLegend`）与**缩放条**（右下 50–400%，100% = 适配宽度）→ **统计行 + 出口**（用作底图 / PNG）。生成中在画布底下浮一条进度胶囊（阶段 + 进度） |
| 生成参数 | 「形态」= 尺寸两键（`世界 3072×1536` / `区域 1024×1024`）+ **宽高输入**（`512–4096`，越界在 `normalizeMapParams` 里夹）+ 大陆四键（地球型 / 三大陆 / 群岛 / 盘古）；「参数」= 八个滑块（陆地比例 / 山脉强度 / 高原强度 / 平原偏置 / 湖泊密度 / 河流密度 / 温度偏移 / 降水偏置），**右侧给当前值**（% / ±% / °C）。范围与 `plugins/map-generator/params.ts` 的 clamp 逐项对齐，否则滑块两端是死区 |
| 重新生成 | 从「地图详情 › 在生成器中重新生成」进入时，生成器带着这张图的 `seed` 与 `map_params` 起步（`initialSeed` / `initialParams`），调完参数再生成，出来的还是同一片大陆 |
| 渲染模式 | **方案 A**：切模式 = 换底图，不叠图层。**生成时一次画完六档并存盘**：`renderMapView()`（插件 Worker 里 `generate` + `render`）逐档渲染 → 落 `.ocstudio/maps/<地图名>-<视图>.png`（固定名，一档一张不会堆积）→ 只有当前档写进 `map_mode` + `map_image`。生成器里那条进度胶囊会报「渲染 等高线 (2/6)」。**切档 = 换路径**：先用 `mapImageExists()` 看盘上有没有这档，有就直接指过去（读一张图，不再等 Worker）；**老地图**（改版前生成的）缺哪档就现场补一张，补完同样落盘。锚点走归一化坐标，不重摆。控制条在切档瞬间禁用、当前档压暗 |
| 种子 | `seed` 是**形状的身份证**：同种子 + 同参数 = 同一张图，所以「换形状」等于换种子。地图详情里种子可点一下复制（带一句「同种子 = 同一张图」），地图列表每行也显示 `seed N` |
| 剖面 | **已实装**：编辑态右下「标注 › 取地形剖面」或右键「取地形剖面」→ 沿两点采样 `renderMapProfile()` → 底部 160px 抽屉 `ProfileDrawer`（折线 + 生物群系色带 + 采样进度）。采样与切视图共用同一份种子 + 参数，所以和屏幕上那张图对得上。**不进控制条**：它是抽屉，不是一张满屏底图 |
| 底图缺失 | 底图文件被移走 / 浏览器里的 `blob:` 已过期时，画布**退回「还没有底图」空态**（`MapCanvas` 的 `onError`），不留破图图标；有标注时不显示居中的空态，避免压住图形 |
| 全屏 | 右上角全屏 / 退出全屏（`Maximize2` / `Minimize2`），Esc 退出；整屏时 `body[data-map-immersive]` 藏状态栏与 `DEV · Mock` 标记 |

### 10.1 政治标注的渲染

**点归实体、线归地图**：城市 / 地点就是锚点；国界与道路没有实体可寄放，存在地图笔记的 `map_annotations`。

- **坐标系是 stage 像素，不是 0–1 的方框**。`viewBox="0 0 stageWidth stageHeight"`，位置 = 归一化坐标 × 尺寸。
  以前用 `viewBox="0 0 1 1"` + `preserveAspectRatio="none"`，在 2:1 的世界地图上顶点圆点会被横向拉成椭圆、
  虚线也被拉长（用户说的「扁扁的」就是这个）。
- **线条色可调**：右键一条国界 / 道路 →「颜色...」→ 12 档色板（`RELATION_COLORS`，与关系图同一套名字，
  落盘存中文名，Obsidian 里也能看懂）+ 国界的填充色（22% 透明）。
- **没选颜色 = 固定深墨**（`--oc-ink-fixed`），**不跟主题翻**：底图是用户内容，暗色主题下的浅灰 `ink`
  铺在浅色地图上基本看不见。每条线下面再垫一道**纸色外壳**（`--oc-paper-fixed`，4px、55%），
  深色海面 / 深色底图上也不会糊。
- 顶点按 `1 / scale` 缩：放大地图时圆点不会长成一坨；线宽与虚线用 `vector-effect` 锁成屏幕像素。
- 画线：编辑态下在空白处右键，或右下「标注」，随后每次点击落一个顶点，底部浮条给「完成绘制 / 取消」
  （Esc 也取消），国界最少 3 点、道路最少 2 点。命中用 `annotationAt()`：面用射线法、线用点到线段距离。

> 超集口径：改版的六档渲染 + 剖面 + 政治标注都要有；我们的锚点 / 图层 / 跳实体是改版没有的，不许退化。

### 10.2 `.ocmap` 地图包（可交换档案）

PNG 是成品：拿到别人的图切不了档、改不了标注、也没法在生成器里接着调。
`.ocmap` 存的正是「重新画得出来」的那几项 —— **底图 + 生成快照（`seed` / `params` / 档位）+ 标注**。

| 项 | 定法 |
|---|---|
| 形状 | `{ format: 'oc-studio-map', version: 1, exportedAt, map: { name, seed, params, view, width, height, annotations }, image?: dataURL }`。标注与 `map_annotations` **同一套结构**（`stringifyAnnotations` 的输出），不再有第二种写法 |
| 纯函数 | `features/map/archive.ts`：解析 / 序列化 / data URL 编解码 / 像素→归一化换算。`npm run audit:maparchive` 36 项断言，全部不碰磁盘 |
| IO | `features/map/archive-io.ts`：先 `createMap(name)` 拿到**去重后的名字**，再按这个名字存底图 —— 反过来两张重名地图会撞同一个文件名 |
| 兼容改版 | 改版的档案同格式，但标注坐标是**像素**、还多一个 `city` 类型。像素标注**不能过 `parseAnnotations`**（那个入口把坐标夹到 0–1，换算前就把 400px 压成 1），解析层单独读一遍、导入时拿图片真实尺寸再除；城市标注跳过并告警 |
| 缺尺寸 | 档案既没写 `width/height`、图片也读不出来时，**跳过标注并告警** —— 把像素坐标当归一化用，线会全部缩进左上角那一小块，比丢掉更误导 |
| 入口 | 右上 ⋯ ›「导出地图包」/「导入地图包…」；地图库为空时空态也有「导入地图包」（第一次用就能进别人的图） |
| JPG | 导出时先铺一层纸色再画图：JPEG 没有 alpha，直接压透明像素会变成纯黑 |

## 11. 社区反馈（2026-11-06）

逐条对齐现状，避免同一件事反复讨论：

| 反馈 | 现状 | 结论 |
|---|---|---|
| 生成完、做了标记，还要不要重新生成 | 锚点归一化、国界道路存地图笔记；**同种子 = 同形状**，换种子才换形状 | 已满足（但换种子会让标记错位，见待做 1） |
| 每次打开地图都要重新加载 | 生成结果**当场存成 PNG**，地图页只读图；现在切档也是读图（六档预生成） | 已满足 |
| 世界地图太大，不知从哪下手 | 生成器里有「区域 1024×1024」 | 待做 2 |
| 想固定形状再生成 | 同种子 + 同参数 = 同一张图；「在生成器中重新生成」带着 seed + 参数起步 | 已满足 |
| 奇幻海盗，犄角旮旯的地点 | 区域图 + 手绘底图 + 锚点 | 已支持 |
| 自定义地域天气（海底洞穴、死亡之眼） | 现在只有「点」（锚点）与「线」（国界 / 道路），没有带属性的面 | 待做 3 |
| 存图片 + 种子就够 | 正是现在的存法：`map_image` + `map_seed` + `map_params` | 已满足 |

### 待做

1. **换种子前提醒**：已有锚点或标注时，重新生成若换了种子，弹一次确认（形状变了，标记会错位）。
2. **区域地图上手**：没有底图时的空态给「生成世界地图 / 生成区域地图」两个入口，别让人一上来面对 3072×1536。
3. **区域标注**（新模型）：面 + 名字 + 一句备注，可着色、可进图例 —— 「海底洞穴 / 死亡之眼 / 地域天气」的载体。现在只有点和线，不承载文字。
4. **种子分享**：`.ocmap` 已带 seed + params；再加一个「复制种子 + 参数」的纯文本，方便发给别人复现。
