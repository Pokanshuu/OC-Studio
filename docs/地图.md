# 地图

> 未实现。定位：地图是**一个视图**（跟时间线、关系图平级），不是一类新实体。

---

## 0. 一句话

**地图不是数据，是看数据的一个角度**——跟时间线把事件摆到时间轴上一样，地图把地点摆到平面上。

---

## 1. 两种地图，别混

| | 手绘地图 | 生成地图 |
|---|---|---|
| 长什么样 | 一张背景图（作者画好的大陆/城市） | 算法生成的轮廓 |
| 数据 | 背景图 + **锚点** | 从参数与种子推导 + 可调参数 |
| 作者投入 | 高（得先有图） | 低（一键出草图） |
| 定位 | **主战场**：最终展示用 | **起步工具**：没图时先有个大概 |

生成器是**官方插件**（`src/plugins/map-generator/`，见 `docs/插件.md` §0.1.1），手绘地图是**内置视图**（`src/features/map/`）。

- 内置侧只认「底图 + 锚点 + 图层」，**不含任何生成算法**；插件被禁用或移除时，手绘地图照常工作
- 插件产出的只是**底图**，锚点仍然必须落在实体上——否则数据和插件绑死（§7 风险 4）
- 插件没有数据权限：不读 Dexie、不写文件，宿主把参数喂给它、把像素接回来

---

## 2. 数据：锚点存在实体上

| 键 | 在哪 | 说明 |
|---|---|---|
| `map_position: { x, y }` | 实体的 frontmatter | 归一化坐标（0–1），与图片尺寸无关——换一张更清晰的地图不用重摆 |
| `map_id` | 实体（可选） | 一个库可以有多张地图（世界 / 某国 / 某城），为空 = 主地图 |

地图自身（`category: 地图` 的笔记）另有五格：`map_image` / `map_width` / `map_height`（底图路径与像素尺寸）、`map_seed` + `map_params`（生成快照）、`map_mode`（当前视图）、`map_annotations`（政治标注）。

**点归实体，线归地图**：国家 / 事件 / 词条 / 城市都是**锚点**（在实体自己的 frontmatter 上，点一下能跳过去）；国界多边形与道路折线没有实体可寄放，才存成地图笔记上的 `map_annotations`（JSON 字符串，坐标同样归一化 0–1）。标注不欠任何笔记，删一条不影响实体。

**`map_mode` 与 `map_image` 是一对**：切视图只改这两个键，`map_seed` / `map_params` 一个字节都不动 —— 快照才是可重画一档图的真源，所以一来一回永远得到同一张图，也不用为每档各存一份参数。手传的底图这两格都是空的，界面据此**不显示视图条**。

背景图存 `.ocstudio/maps/<名>.png`，随库走。

**为什么归一化**：`graphPosition` 是绝对坐标，因为关系图没有底图；地图有底图，底图会换（草图 → 精修），绝对坐标会全废。

## 3. 与实体的联动

| 方向 | 行为 |
|---|---|
| 实体 → 地图 | 「地点」组件里出现「在地图中查看」；有锚点就定位过去 |
| 地图 → 实体 | 点锚点 = 跳转那个国家 / 事件 / 词条 |
| 地点字段 | 现在是一行文本（`place`），**锚点存在实体上而不是地点字段里**——地点是给读者看的名字，锚点是给地图用的坐标 |

事件也可以有锚点（"这里发生过什么"），所以地图上能叠一层事件图层。这是它比"插入一张图片"多出来的全部价值。

---

## 4. 交互（第一版只做这些）

- 缩放 / 平移（与关系图同一套手势与 `MIN_ZOOM`）
- 点锚点 → 打开实体
- 拖动锚点 → 改位置（**写回实体 frontmatter**；移动端只读）
- 图层开关：国家 / 事件 / 词条（对应实体类型）
- **不做**：路径规划、距离测量、经纬度投影、多层地形——那是 GIS，不是设定集

---

## 5. 与模板的关系

地图可以作为一个 **block 组件**塞进模板（比如国家页显示"本国位置"的缩略）。缩略态只读、不可拖。

---

## 6. 不做

- 真 GIS（投影 / 经纬度 / 等高线）
- 在应用里画地图（画图是外部工具的事，我们只认一张背景图 + 锚点）
- 地图之间互相嵌套的层级导航（先只有"一个库多张图"）

---

## 7. 风险

| 风险 | 说明 |
|---|---|
| 底图换了，锚点全歪 | 归一化坐标能扛"换分辨率"，扛不住"构图改了"——换了构图就该重摆，UI 要提示这一点 |
| 大底图性能 | 与主题背景图同一个问题：上屏用压缩版，原图只在导出时用 |
| 锚点重叠 | 两个国家挨得近时锚点会叠，需要错开或聚合（与关系图同一套问题） |
| 生成器的产出算谁的 | 插件生成的地图只是"底图"，锚点仍然必须落在实体上，否则数据和插件绑死 |

## 10. 2026-11-05 改版（苹果地图式的整屏界面）

口径：**地图是一整块画布，所有控件都是压在它上面的浮层**；没有页头、没有卡片边框。

| 项 | 定法 |
|---|---|
布局 | `MapView` 整块铺满内容区（`MapCanvas` 的 `bleed`），画布右下保留缩放 / 适配 |
查看 / 编辑 | **默认查看态**（`oc-map-mode`，记住上次）：能缩放平移、点锚点跳实体；锚点不可拖、不出菜单。编辑态才出现添加锚点 / 底图 / 生成 / 导出 |
地图选择 | 左下「图层」卡片**顶部**是当前地图名 + ⌄，点开是**天气 App 式的卡片列表**（`MapSwitcher`）：左边名字压在纸色实底、向右渐隐到不模糊缩略图（`from-paper` 渐变 + 反向 mask 的 `backdrop-blur`）；行内可重命名 / 删除，底部新建。打开选择器时**图层卡片先收起**，两张卡片不叠在一起 |
地图库 | 图层卡片右上角的 Library 图标 / 选择器底部「地图库」→ `MapLibraryDialog`（680 宽）：每张图一行，给尺寸 / 类型（生成图 / 手绘底图 / 空白）/ 锚点数 / 标注数 / 是否当前；行内重命名、删除（`AlertDialog` 确认），底部新建。锚点按 `map_id`（地图名）统计，空 `map_id` 单独报「未归属」 |
图层卡片 | 同一张卡片里分「显示」（国家 / 事件 / 词条）与「编辑」（加锚点 / 设底图 / 移除底图 / 生成地图 / 导出）两组 |
生成器入口 | **没有底图时**，底部居中直接给一个「生成地图」（`BTN_PRIMARY`）—— 藏在「编辑态 › 图层 › 生成地图」三层里没人找得到。有底图后仍在图层卡片的编辑组里重生成 |
生成参数 | 「形态」（尺寸 `世界 3072×1536` / `区域 1024×1024`、大陆 `地球型 / 三大陆 / 群岛 / 盘古`）+ 六个滑块（陆地比例 / 山脉强度 / 湖泊密度 / 河流密度 / 温度偏移 / 降水偏置）。范围与 `plugins/map-generator/params.ts` 的 clamp 逐项对齐，否则滑块两端是死区。预览列与参数列各自滚，**「用作底图 / PNG」固定在左下**，屏矮也看得到 |
渲染模式 | **已实装**（方案 A：切模式 = 换底图，不叠图层）。画布下方居中的视图条 `MapViewStrip` 六档：`terrain / contour / temperature / moisture / biome / political`。切档流程：读存的 `map_seed` + `map_params` → `renderMapView()`（插件 Worker 里 `generate` + `render`）→ 落 `.ocstudio/maps/<地图名>-<视图>.png`（固定名、**原地覆盖**，一档一张不会堆积）→ 写 `map_mode` + `map_image`。锚点走归一化坐标，不重摆。**只有生成过的地图才显示这条**（手传底图没有可重画的快照） |
剖面 | **已实装**：右键「取地形剖面」→ 沿两点采样 `renderMapProfile()` → 底部 160px 抽屉 `ProfileDrawer`（折线 + 生物群系色带 + 采样进度）。采样与切视图共用同一份种子 + 参数，所以和屏幕上那张图对得上。**不进视图条**：它是抽屉，不是一张满屏底图 |
图例 | **已实装**：`MapLegend` 压在左下（图层按钮上方），按当前档位给色带（地形低→高、温度、降水）、生物群系色块或政治标注图例；色值照抄渲染器，不自己配色 |
底图缺失 | 底图文件被移走 / 浏览器里的 `blob:` 已过期时，画布**退回「还没有底图」空态**（`MapCanvas` 的 `onError`），不留破图图标；有标注时不显示居中的空态，避免压住图形 |
政治标注 | **已实装（线 + 区域填充）**：编辑态下**右键空白处** →「画国界」/「画道路」，随后每次点击落一个顶点，底部浮条给「完成绘制 / 取消」（Esc 也取消），国界最少 3 点、道路最少 2 点。右键**落在已有国界上**菜单有「填充色...」→ 12 档色板 + 无填充；`fill` 存色板中文名，渲染 22% 透明，道路不写。右键**落在已有标注上**还有「删除国界 / 删除道路」（命中是 `annotationAt()`：面用射线法、线用点到线段距离）。渲染在 `AnnotationLayer` —— 一个 `viewBox="0 0 1 1"` 的 SVG，归一化坐标直接用，`vector-effect` 锁描边像素，描边走 `currentColor` 跟主题。**点不重复做**：城市 / 地点就是锚点，`地图` 上右键不放「放城市」 |
全屏 | **已实装**：右上角全屏 / 退出全屏（`Maximize2` / `Minimize2`），Esc 退出；整屏时 `body[data-map-immersive]` 藏状态栏与 `DEV · Mock` 标记 |

> 超集口径：改版的六档渲染 + 剖面 + 政治标注都要有；我们的锚点 / 图层 / 跳实体是改版没有的，不许退化。
