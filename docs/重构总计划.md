# 重构总计划

> 2026-11-04 · v1。总纲是 `docs/模板.md` §1.4 那一条：**写进文件的只有事实，列表 / 反向 / 统计一律算出来**。
> 这份文档只回答三件事：**现在有什么债、按什么顺序还、每一阶段怎么算做完**。
> 领域细节仍然在九份文档里，这里不复制，只做索引与排序。

---

## 0. 一句话

把「一堆能跑的功能」收成四层可替换的结构 —— **内核（数据 / 落盘）→ 组件（展示）→ 外壳（界面）→ 能力（模板 / 主题 / 插件 / Agent）**，
同时把开发体验做到「一天能安全地改十个界面」：有 CI、有回归、有组件沙盒、有明确的文件边界。

四个「现代化」各自对应一条主线：

| 目标 | 主线 | 判定标准 |
|---|---|---|
| 现代化的输入 / 编辑体验 | **L1 Input** | 写东西时手不离键盘；格式化、插图、引用、撤销都不用找菜单 |
| 现代化的界面 | **L2 Interface** | 任意两处同类控件长得一样；间距 / 圆角 / 动效只有一套来源 |
| 现代化的扩展与自定义 | **L3 Extend** | 模板、主题、字段、插件四件事都不改内核代码 |
| 现代化的开发体验 | **L4 DevEx** | 改一个组件不用读三个文件；提交前一条命令给出全部结论 |

## 1. 现状（三条结论）

### 1.1 功能面：已经「齐」，但只是「齐」

PR #5 的能力已经吸收（小说 / 地图 / 关系边 / 树表 / 角色文件夹 / 地图生成器），封面卡在作者手里收尾。
问题是这些能力**各长各的**：小说树与世界树两套行样式（刚收口）、相册两套网格（`ImageGalleryGrid` 与 `GlobalAlbum`）、
命令面板与移动端搜索两套 UI、四类实体四套编辑器管线。

### 1.2 架构债：`docs/现状问题.md` 的两条根因仍然成立

1. **没有「数据 vs 展示」这条线** → 反向列表被存了下来（`country.characters` / `country.events` 镜像双写）。
2. **「一类实体一套编辑器」** → 展示逻辑复制了四遍（角色 / 事件 / 国家 / 词条）。

其余问题（关系只能连角色、同一事实三种写法、标签没有位置、时间线泳道无语义）都是这两条的下游。

### 1.3 工程债：能跑，但改起来越来越慢

| 症状 | 证据 | 影响 |
|---|---|---|
| 大文件回潮 | `NovelTree` 791 行、`vault-persist` 775、`scan` 698、`use-entity-workspace` 662 | 改动半径大，review 只能看 diff 局部 |
| lint 不可用 | 全量 `npm run lint` 报 4.7 万条（扫进了 `public/`、`out/` 的构建产物） | 等于没有静态检查 |
| 没有回归网 | 只有 `scripts/*-check.ts`（好，但只覆盖 vault / 导出 / 封面算法） | 界面与交互改动零保护 |
| 没有 CI | 全部靠本地手动跑 | 「谁最后提交谁负责」不可持续 |

## 2. 目标状态（四层）

```
┌──────────────────────────────────────────────────────────┐
│ 能力层  模板 / 主题 / 字段 / 插件 / Agent（只通过注册表接） │
├──────────────────────────────────────────────────────────┤
│ 外壳层  AppShell · 列表页 · 编辑器壳 · 浮层 · 动效 · 键盘  │
├──────────────────────────────────────────────────────────┤
│ 组件层  ComponentSection + 组件 registry（闭集，渲染只一份）│
│         含封面卡：列表网格 / 书架 / 头图三种形态共用一份    │
├──────────────────────────────────────────────────────────┤
│ 内核层  实体 / 字段词表 / 仓储 / 落盘队列 / 导出 / 索引    │
└──────────────────────────────────────────────────────────┘
```

**硬边界**（写进 review 清单）：

- 组件层不许 import 外壳层；内核层不许 import React。
- 展示逻辑只算不存；写文件只写事实（`模板.md` §1.4）。
- 主题只能改令牌，不能改结构；插件只能走 RPC，不能碰 DOM / Dexie。
- 一类实体的差异只允许出现在「模板文件 + 注册表参数」里，不允许再出现 `if (kind === 'character')` 分支。

### 2.1 封面卡是组件，不是某个页面的私有实现

**定性**：封面卡（`lib/cover/` + `components/shared/cover/`）是未来展示层的主力组件 —— 列表网格、小说书架、
实体头图、（后续）导出卡与模板 block 都复用它。它属于**组件层**，不是「某个列表的样式」。

| 维度 | 契约 |
|---|---|
| 形态 | `variant: 'card'`（列表网格，3:2 / 2:3 由调用方给）/ `'shelf'`（书架）/ `'banner'`（头图 3:2） |
| 输入 | 实体摘要（封面图、标题、简介、小字、头像/徽章）+ `variant` + `tuning`（版式参数） |
| 输出 | 纯展示：画布（`CoverArt`）+ DOM 文字块；**不含数据读取、不含路由** |
| 参数来源 | `lib/cover/tuning.ts` 是唯一源；模板阶段一后由模板参数覆盖默认值 |
| 降级 | 无图 → 纸色底 + 衬线标题；无彩度图 → 中性色（`color.ts` 不猜色相）；缺字段就少一行，不占位 |
| 性能 | 进视口才画、一帧两张、按画布去重（`docs/封面卡.md` §5） |
| 验收 | `npx tsx scripts/cover-check.ts` 32 项；三个消费方传**同一形状**的 props |

迁移路径：现阶段允许作者继续调算法与版式；**P0 定稿后冻结契约**（props 形状 + variant 枚举），
之后算法内部随便改，消费方不再改结构。界面统一时，封面卡只消费共享件与令牌，不再自带行 / 浮层样式。

## 3. 四条主线

### L1 输入与编辑（Input）

**现状**：`EditorCore` 是唯一实例（好），但能力停在「富文本 + 图片块 + `[[ ]]` + `@`」。
写作时的现代习惯（斜杠命令、块拖拽、粘贴 Markdown / 图片、表格操作、快捷键可发现）大量缺失或零散。

| # | 工作项 | 做法 | 验收 |
|---|---|---|---|
| L1.1 | 斜杠命令面板 | 复用现有块面板的渲染器，命令表由注册表给 | 输入 `/` 出面板，键盘可选，Esc 关闭 |
| L1.2 | 块级拖拽手柄 | 行首 hover 手柄，拖拽换位；与 `list-dnd` 共用传感器参数 | 段落 / 图片 / 表格 / 引用都能拖 |
| L1.3 | 粘贴管线 | `paste` 事件统一处理：HTML → ProseMirror、Markdown 文本 → 结构、文件 → `ImageBlock` | 从浏览器 / Word / 微信粘贴都不炸 |
| L1.4 | 图片粘贴 / 拖入 | 走 `image-service` 落盘，失败回滚 | 粘贴截图直接成块 |
| L1.5 | 表格操作条 | 行列增删、对齐、表头；复用 `BubbleMenu` 的定位 | 单元格内出现条，移出消失 |
| L1.6 | 撤销粒度 | 合并同一输入段落；图片 / 结构操作单独一步 | Ctrl+Z 一次退一件事 |
| L1.7 | 保存状态可视化 | 标题栏右侧一个状态点（已保存 / 保存中 / 失败可重试） | 三态可复现 |
| L1.8 | 大纲 / 专注 / 字数 | 大纲读 `buildEntryTree`（不新建第二套）；专注模式隐藏外壳 | 小说与词条共用 |
| L1.9 | 快捷键总表 | 一张表驱动（`keymap.ts`）+ `?` 弹出 | 所有快捷键可在 UI 里查到 |
| L1.10 | IME / 移动端回归 | 中文输入法组字期间不触发保存 / 快捷键；移动端选词条与键盘工具栏回归 | 组字不闪、不误存 |

**不做**：Notion 式「正文里嵌任意块」（`模板.md` §12）；双模式（编辑 / 浏览）。

### L2 界面（Interface）

**现状**：令牌已经存在（`ui-tokens.ts` + `globals.css` + 两个 audit），但**组合方式**还在各写各的：
同一个「列表行」在三处三种 hover，同一个「空态」三种写法，动效时长随手写。

| # | 工作项 | 做法 | 验收 |
|---|---|---|---|
| L2.1 | 组件原子补齐 | 在 `ui-tokens` 之上补 **行 / 卡 / 分区 / 工具条 / 空态 / 抽屉** 六个共享件；`TreeRow` 是第一个样板 | 同类控件只有一个实现 |
| L2.2 | 动效令牌 | `--oc-duration-*` / `--oc-ease-*` 进 `globals.css`；禁止就地写 `duration-200` | `audit:design` 新增 `motion-literal` 规则 |
| L2.3 | 层级登记 | z-index 只从 `z-index.ts` 取（已有部分） | 新增浮层不手写 `z-50` |
| L2.4 | 密度与字号 | 三档密度（紧凑 / 标准 / 宽松）落在令牌，不改结构 | 设置里可切，列表与编辑器同步 |
| L2.5 | 搜索合并 | `MenuBarSearch` 与 `MobileSearchOverlay` 变成一个内核 + 两套壳 | 结果数据结构同一份 |
| L2.6 | 设置信息架构 | 按「世界 / 界面 / 数据 / 高级」重排；主题、模板、标签、插件各归其位 | 每个设置项只有一处入口 |
| L2.7 | 命令面板 | 一个面板聚合导航 / 命令 / 搜索 / 最近 | `Ctrl+K` 唯一动作 |
| L2.8 | 移动端对齐 | 触控目标 ≥ 40px、底部安全区、抽屉与长按菜单统一 | 关键流程无「桌面才有」 |
| L2.9 | 可访问性 | 焦点环、`aria-*`、键盘可达、对比度（主题 audit 扩展） | 全站 Tab 一遍不断链 |

### L3 扩展与自定义（Extend）

**现状**：文档齐全、地基一半（令牌登记、插件形状、journal actor），但用户能改的东西还只有字段表。

| # | 工作项 | 依赖 | 验收 |
|---|---|---|---|
| L3.1 | **模板阶段一**：`ComponentSection` 壳 + 组件 registry + 模板文件 + 渲染循环 | 无（零迁移） | 编辑器由组件拼装，数据仍写原列 |
| L3.1b | **封面卡进 registry**：`Cover` 组件三种形态（`card` 列表网格 / `shelf` 书架 / `banner` 头图），版式参数来自模板而非散落常量 | L3.1 | 三个消费方只传 props，不再各自写卡片结构 |
| L3.2 | 模板编排界面 + 参数抽屉 + 实时预览 | L3.1 | 设置里能排出一个自定义角色页 |
| L3.3 | 标签管理（改名 / 合并 / 删除 / 统计 / 整理） | 无 | 标签只有一个入口 |
| L3.4 | 图片 / 网页导出 + 预设（`.ocstudio/exports.json`） | L3.1、`save_bytes` | 导出角色卡与静态站 |
| L3.5 | 主题：3–5 套官方 + 应用级（令牌 + 材质）+ 背景图管线 | L2.1 | 换主题不动结构；背景与 Mica 互斥 |
| L3.6 | 字段自定义收尾（国家字段表、找回入口、hover 快捷隐藏） | 字段表 | 四类实体同一套字段 UI |
| L3.7 | 插件注册表 + 地图生成器「可禁用」验证 | L3.1 | 禁用后视图降级不报错 |
| L3.8 | Agent 只读能力层（`Caller` + 权限入口检查）+ 图鉴切片 | `payload` 导出器 | 外部可读、默认只读 |
| L3.9 | MCP 适配器 | L3.8 | 同一份工具定义导出 `tools/list` |

**明确不做**：用户自定义组件渲染（插件 + 沙箱是唯一通路）；插件带任意脚本。

### L4 开发体验（DevEx）

| # | 工作项 | 做法 | 验收 |
|---|---|---|---|

## 8. 并行边界（避免互相踩）

| 区域 | 归属 | 规则 |
|---|---|---|
| `src/lib/cover/**` · `components/shared/cover/**` · 封面卡调参 | 作者 | 算法与版式作者主导；**契约（props / variant）由组件化线定**，定稿后消费方不改结构 |
| `src/lib/vault/**` · `src-tauri/src/vault*` | 内核线 | 改动必须跑 vault 五连检 |
| `src/components/shared/**` · `ui-tokens.ts` | 界面线 | 新共享件先进沙盒页 |
| 模板 / registry | 组件化线 | 先定契约再动消费方 |
| 插件 / 主题 / Agent | 能力线 | 只通过注册表接，不改内核 |
| 文档 | 各线自维护 | 领域文档只写「怎么做」，todo 只写「还没做」 |

同一阶段内，**一条线一个人**；跨线改动先在本文件登记，避免同文件并发。

## 10. 风险与回滚

| 风险 | 触发信号 | 应对 |
|---|---|---|
| 组件化把写作面变成「配置现场」 | 编辑器里出现卡片边框 / 悬停工具条 | 契约守住：写作面只看得到小节标题（`模板.md` §1.2） |
| 模板与渲染器漂移 | 配了没反应的组件 | `audit:templates` + 每个组件必须有渲染器 |
| 显式关系边不可逆 | 旧版读不懂新文件 | 先出 `.ocbak` 全量备份 + 双读一版 |
| 大重构期间无法发版 | 分支长期不合 | 每阶段独立可发；feature flag 置于设置 |
| 封面卡与统一界面冲突 | 两套行 / 浮层样式 | P0 后封面卡只消费共享件 |
| 封面卡 WIP 被误改 | 文件在别人名下被编辑 | 表 §8 的归属约定 + review 检查 |
