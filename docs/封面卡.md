# 封面卡（角色 / 国家 / 事件网格视图）

> 网格视图的卡片样式：照片下缘**逐行递增模糊 → 完全混色**，标题压在模糊区上，
> 简介与小字落在色块里。
> 算法与版式照搬 [Simple_Cover](../../Simple_Cover)（`js/engine.js` + `styles.css`），
> 参数集中在 `src/lib/cover/tuning.ts`。
>
> 代码：`src/lib/cover/`（算法）+ `src/components/shared/cover/`（组件）。

---

## 1. 一幅画是怎么画出来的

画布按卡片宽度 × 设备像素比出图（最长边 760px 封顶），四步：

```
┌──────────────────────────────┐
│        照片（贴顶、可留边）        │  ← 只按宽度铺满，左右永不裁
│   下缘逐行递增模糊 → 完全混色      │  ← 模糊从「模糊起点」开始
├──────────────────────────────┤  ← 照片块在「自然高度 / 上限」处结束
│  色块：标题 / 简介 / 一行小字      │  ← 由 DOM 画，不烧进画布
└──────────────────────────────┘
```

1. **色块铺满整张画布**（不是照片上盖的遮罩）—— 它天然越过照片的左、右、下边界，
   文字才能落在实色区里。
2. **照片**画在自己的一块离屏画布上，再贴回主画布（`inset > 0` 时带 2px 圆角裁切）。
   **照片块的高度只由宽度决定**（`photoPlateHeight`）：

   ```
   自然高度 = 卡片宽 × (图片高 / 图片宽)
   块高度   = min(自然高度, 画布高 × 照片高度上限)
   ```

   所以 3:2 的横图在 7:6 的卡上只占约 78% 高，下面那段本来就是色块；
   图与卡同比例时正好铺满、**一点不裁**；只有竖图超过上限时才裁上下。
   **永远不裁左右** —— 头图都是横的，左右一裁等于把构图砍掉。
3. **渐进模糊**：每一行的半径按 smoothstep 递增，所以不会出现一层一层的遮罩边：

   ```
   r(y) = radius · 0.46 · smoothstep((y − start) / (H − start))
   ```

   做 3 次「水平可变半径 + 垂直可变半径」的可分离盒式卷积（前缀和，O(像素)）。
   只算**起点以下**那一段 —— 上面是清晰的，白算一遍没意义。
4. **按行衰减 Alpha**：照片块自身高度的 78% 起逐渐透明，照片就融进色块。
   这一步**与模糊起点无关**：照片比模糊起点还矮时（800×300 这种超宽图），起点落在照片
   外面 —— 如果这时候整段跳过，照片就会一刀切在色块上。所以切片从
   `min(模糊起点, 淡出起点)` 开始，半径可以是 0，淡出永远跑。
5. 再叠**混色渐变**（画布 51% 起，88% 全实色）、一点点底部厚度、暗角、胶片颗粒。

## 2. 取色（`color.ts`）

权重按像素饱和度给（`0.45 + sat × 1.7`），压掉过亮 / 过暗的像素，然后：

| 情况 | 结果 |
| --- | --- |
| 有彩度（`(max−min)/max ≥ 0.06`） | 用图**自己的色相**，饱和度只做 0.10–0.45 的下限/上限，亮度压到 0.15–0.26 |
| 无彩度（线稿 / 黑白照） | 中性炭黑，**不猜色相** |
| 没有图 | 中性炭黑；有头像 / 国徽时改拿它取色 |

> 参考实现在无彩度时会硬塞苔青（固定色相 0.42 + 饱和度下限 0.22），线稿一律变深绿。
> 那是给「风景照片封面」调的兜底，**不要搬回来**。

亮度永远压到 0.15–0.26：压在色块上的米白标题（`--oc-paper-fixed`）才读得清。

### 黑白模式（设置 → 个性化 → 封面卡配色）

**不是固定墨色，而是跟着主题走**：块色直接读 `--oc-paper-card`
—— 亮色主题是纸色（`#F3EFE9`），暗色主题才是墨色（`#2D2B28`）。

一块深色底会牵连三处「默认底色是暗的」的假设，改这块必须一起看：

1. **文字要翻**：块色跟着主题走，文字就不能用 `*-fixed`，
   要用 `text-ink` 一族（`COVER_TITLE_MONO` / `COVER_INTRO_MONO` / `COVER_META_MONO`，
   分隔线也跟着换成 `border-line`）。
2. **水印、暗角、底部厚度要看亮度**：`luminance(tint) > 0.5` 时水印改成「压暗」而不是「提亮」，
   暗角与底部厚度降到几乎看不见（否则纸色底会发脏）。
3. **切主题要重画**：块色不是常量，靠 `useIsDarkTheme()`（MutationObserver 订阅 `<html class>`）
   重新读令牌并触发重绘；直接在一次渲染里读 `classList` 会一直用错分支。

老版本把 `'ink'` 存进 `settings.coverTintMode`，`normalizeTintMode()` 会把它读成 `'mono'`。

## 3. 参数（`tuning.ts`，面板实时调）

默认值 = **2026-11-04 定稿**，比参考实现更「照片为大」：混色更早开始也更晚收完、颗粒更重。

> 比例 **7:6**（≈1.17）。头图基本都是横向的，卡片就按接近原图的比例来，
> 照片只按宽度铺满 —— **左右一点都不裁**（见 §1）。竖比例不要用，会把横图砍掉大半。

| 字段 | 含义 | 默认 | 范围 |
| --- | --- | --- | --- |
| `aspect` | 卡片比例（宽 / 高） | `7/6`（≈1.17） | 1:1 / 7:6 / 4:3 / 3:2 |
| `inset` | 照片左右留边（画布宽 %） | `0` | 0–12 |
| `photoHeight` | 照片高度**上限**（画布高 %） | `100` | 40–100 |
| `blurStart` | 模糊起点（画布高 %） | `47` | 10–85 |
| `blur` | 模糊强度（1080 宽下的 px，内部再 ×0.46） | `30` | 0–80 |
| `mixStart` | 混色起点（画布高 %） | `51` | 20–90 |
| `mixPoint` | 混色完成（画布高 %） | `88` | 40–98 |
| `grain` | 颗粒 | `57` | 0–100 |
| `textBottom` | 文字块底边距（画布高 %） | `5` | 0–40 |
| `textLeft` / `textRight` | 文字块左右边距（画布宽 %） | `6.5` | 0–20 |
| `titleScale` | 标题字号（卡片宽度的 %，即 `cqw`） | `8` | 3–16 |
| `titleMax` | 标题字号上限（px） | `24` | 12–52 |
| `introSize` | 简介字号（px） | `12` | 8–22 |
| `metaSize` | 小字字号（px） | `10` | 7–18 |

**标题压在模糊区上**是这张卡的关键：`photoHeight` 与 `textBottom` 要一起看 ——
让标题落在「模糊起点 → 照片结束」之间，简介与小字落到色块里。
`photoHeight` 是**上限**：横图的自然高度低于它时按自然高度走（下面那段就是色块），
所以调高它不会把横图拉高，只会让竖图少裁一点。
改其中一个先看另一个，否则会退回「文字全在色块里」的普通卡片。

存 `localStorage`（`oc-cover-tuning`，带 `version`）。**改默认值时把 `COVER_TUNING_VERSION` +1**，
否则用户本地那份旧参数会一直盖住新默认值（定稿那次就是这么踩的）。

## 4. 文字块（DOM）

```
┌──────────────────────────────┐
│ (头像)  标题（衬线）            │  ← 有头像才左右排；没有就标题顶到左边
│         小字：国籍 / 时间        │  ← 有才渲染
│ 简介（两行截断）                │  ← 有才渲染
└──────────────────────────────┘
```

**不预留空位**：缺头像 / 缺小字 / 缺简介就少一行，标题跟着上下移动 ——
「给缺的字段留白以求对齐」看起来是整齐了，但空出来的那一大块色块更碍眼。
文字块整体从卡片底部往上排（`textBottom`），所以内容多的卡文字向上长。

为什么是 DOM 而不是画进画布：

- 可以选中、可以复制，无障碍树里有它；
- 字号 / 字体走设计令牌（衬线标题 + 黑体简介），换主题不糊；
- 字数变化不用重画整张图。

字号按字符数降档（≤10 / ≤16 / ≤24 / >24 依次 ×1 / 0.81 / 0.67 / 0.56），
下限保证小卡片上也读得清，上限由 `titleMax` 给。

## 5. 性能

一屏二三十张卡不能一起抢主线程：

- **进视口才画**：`IntersectionObserver` + 280px 提前量；另加 1.2s 兜底（IO 回调
  在无头浏览器 / 刚被 `display:none` 挡住的容器里可能一次都不来）；
- **一帧两张**：渲染队列（`queue.ts`），按画布去重 —— 拖参数滑杆时每秒几十次请求
  只保留最后一次；
- **只糊需要糊的那一段**：起点以上的行一行都不算；
- **图片缩到 1024px** 再缓存（最多 24 张），画布最长边 760px。

## 6. 怎么调

「视图 → 封面卡参数」，或 `Ctrl/Cmd + Shift + K`。面板里拖滑杆 → 所有卡片实时重画；

## 7. 验证

```bash
npx tsx scripts/cover-check.ts   # 模糊 / 取色 / 照片块尺寸 46 项断言（纯函数，不碰 DOM）
npm run audit:design             # 设计令牌体检，0 违规
npx tsc --noEmit
```

`cover-check` 覆盖：半径 0 时像素不变、起点那行不漏糊、底部被抹开、纯色图模糊后
仍是纯色（左右边缘不变暗）、Alpha 单调不增、输出像素合法、1×1 / 空切片不崩、
有彩度保色相 / 无彩度走中性 / 灰度像素不提色、黑白模式的亮度分界与旧值迁移、
**照片块按宽度铺满（横图不裁左右、竖图只裁上下）**。

## 8. 与参考实现的差异（有意为之）

| 项 | 参考 | 这里 | 为什么 |
| --- | --- | --- | --- |
| 照片位置 | 左右各缩进 6.5%、顶部 4.5% | **满幅贴顶**（`inset = 0`） | 四周留边在网格里像「套了个框」 |
| 照片裁切 | `cover`（左右也裁） | **只按宽度铺满，左右永不裁** | 头图都是横的，左右一裁就砍构图；横图矮下来的那段正好当色块 |
| 文字 | 画进画布 | **DOM** | 见 §4 |
| 无彩度取色 | 固定苔青 | **中性炭黑** | 见 §2 |
| 无头图 | —— | 中性色 + 衬线首字水印 | 没有图就没有颜色信息，不编 |

## 9. 已知取舍

- 卡片不显示头像以外的头像类信息（行视图仍保留完整字段）；**头像 / 国徽**放在标题上方，
  没有就不占位。
- 事件卡的「编辑于 …」不上卡（在行视图里），卡片底部小字只放事件时间。
- 无头图的卡只有色块 + 首字，多张并排时容易雷同 —— 这是「不编颜色」的代价；
  需要时给实体补一张头图。
