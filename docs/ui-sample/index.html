立绘

正文

灰烬教团的第一位、也是唯一一位首席记录官。她的职责不是书写历史，而是保存那些拒绝被写下的东西——名字、口音、一首没唱完的歌。

生平

生于西境城邦伊尔，父母皆为引水渠的维护匠人。第三灰风季吞没伊尔时她九岁，随幸存者沿渠徒步四十日抵达中央高地。
