# 全局导出器（导出中心）

> **一句话**：五种导出器（海报 / 静态网站 / 文档 / 关系图 / 完整备份）共用同一个界面：
> 左边所见即所得，右边选内容、背景、版式与参数。导出逻辑并不统一（DOM 截图 / 拼 HTML / 文本 / JSON），
> 统一的是**操作顺序**与**配置面的墨水**。

入口：`文件 › 导出中心…`、`设置 › 数据 › 导出中心…`、移动端「更多 › 导出中心」、
模板编排行顶栏「导出图片」（带当前对象直接落地到海报页签）、
关系图「更多 › 导出图片…」（直接落在关系图页签）。

代码入口：`src/components/shared/export/ExportCenter.tsx`。

## 1. 布局

```
┌──────────────────────────────────────────────────────────────┐
│ ← 导出中心                                                    │
├──────────────────────────────────────────────────────────────┤
│  海报  网站  文档  关系图  备份                              │  ← 页签：2px 墨线下划线
├───────────────────────────────────┬──────────────────────────┤
│                                   │ 对象 / 版式 / 画布 …     │
│        左：真实预览               │                          │
│        （同一份渲染函数）         │ 右：配置（320px，自己滚动）│
│                                   │                          │
├───────────────────────────────────┴──────────────────────────┤
│                                   │ 尺寸提示      导出按钮    │
└──────────────────────────────────────────────────────────────┘
```

- **只有一个出口**：左上角「← 返回」就是关闭（Esc 同效）。以前右上角还挂一个「关闭」，两个按钮做一件事。
- **焦点收进来**：打开时焦点落在返回按钮上，Tab 在面板内循环（Shift+Tab 从第一个绕回最后一个），关闭后焦点还给打开它的那个菜单项。
- **页签可用键盘走**：← → 切换、Home / End 跳首尾；`role="tablist"` + `aria-selected`，屏幕阅读器认得这是页签不是按钮。
- **配置行会换行**：`ExportRow` 的值区可折行，窄窗口不会把面板撑出横向滚动条。
- **滑杆统一外观**：样式在 `export/controls.tsx` 的 `RANGE_CLASS`（轨道一条 2px 细线、拇指一个 12px 墨点），
  不用各平台长得都不一样的原生样式。**别放回全局样式表** —— `globals.css` 被整体重写过一次，
  原来的 `.oc-range` 就那么没了，滑杆当场退回 Chromium 的蓝圆点。
- **预览不是另一张稿**：海报用 `PosterCanvas`、网站用同一个 `buildSite()`、
  文档用同一份生成函数、关系图用同一个 `renderRelationGraphCanvas()`、备份用真实库存计数。
- 窄屏（≤767px）：上下分区，预览固定 46vh（`.export-preview`），配置吃剩余高度并自己滚动。
  这两个类的媒体查询在 `globals.css`，不用 `max-md:h-[…]` —— 列向 flex 里 `flex-basis: 0` 会吃掉高度。

## 2. 海报（`poster`）

### 2.1 数据从哪来

`src/lib/export/poster/subjects.ts` 只做只读装配：

| 对象 | 封面 | 字段 | 正文 | 关系 / 画廊 |
|---|---|---|---|---|
| 角色 | 头图 → 头像 → 画廊首图 | 种族 / 元素 / 职业 / 阵营 / 国籍 / 身高 / 生日 + 自定义 | `document` → `lifeStory` | 相关角色 / 画廊 + 立绘 |
| 事件 | 头图 → 图集首图 | 参与角色 / 相关国家 / 地点 + 自定义 | `document` → `content` | — / 图集 |
| 国家 | 头图 / 国旗 | 体制 / 地理 / 文化 / 上级 + 自定义 | `document` | 居民（查询） / — |
| 词条 | 3:2 封面 | 上级 / 分类 + 自定义 | `document` → `content` | 引用列表 / — |

- 旧数据里的正文是 HTML 字符串时，回落也要过 `plainTextOf()`，不能把 `<blockquote>` 当字面量画出来。
- 笔记的模板名：单篇 `模板:` → 分类绑定 → 内置「词条」。

### 2.2 六套版式（`poster/catalog.ts`）

| id | 名字 | 观感 | 默认封位 | 默认对齐 / 列 |
|---|---|---|---|---|
| `editorial` | 刊首 | 杂志封面：题头小字、大衬线标题、两栏定义表 | top（宽幅右侧通栏） | 左 / 2 |
| `noir` | 夜色 | 电影海报：封面满幅 + 墨色渐变，标题沉底 | background | 左 / 2 |
| `archive` | 档案 | 博物馆展签：编号、等宽 key/value、方图 | left | 左 / 1 |
| `frame` | 胶片 | 电影画幅：细画框、字幕条、大量留白 | top | 左 / 1 |
| `mono` | 素白 | 独立杂志扉页：靠字号层级与留白 | top（小方图在标题右） | 左 / 1 |
| `split` | 双栏 | 作品集内页：40% 满高封面 + 右侧文字 | left（宽幅顶部通栏） | 左 / 2 |

- 组件装配：`components/shared/poster/registry.tsx`（id → 组件）
- 元数据：`lib/export/poster/catalog.ts`（无 React，脚本可读）
- 正文流：`components/shared/poster/blocks.tsx`（`PosterFlow`），三套皮肤 `paper / archive / cinematic`

### 2.3 可调参数（右侧「画布 / 封面与图片 / 文字排版 / 内容」）

| 参数 | 作用 |
|---|---|
| 版式 | 六套之一；切到夜色自动墨底、切回纸底 |
| 尺寸 | 角色卡 3:4 / 方卡 1:1 / 竖版 9:16 / 横幅 16:9（固定 1080 宽） |
| 留白 | 紧凑 40 / 标准 68 / 宽松 96 |
| 背景 | 纸色 / 透明 / 墨色 / 网格纸 / 渐变 / 封面模糊 |
| 封面位置 | 自动 / 顶部 / 左侧 / 右侧 / 满幅 / 不显示（只列版式支持的值） |
| 封面大小 | 封面**遮罩**在其区域里的倍率 70–130%（改的是框，不是图） |
| 图片缩放 | 图在遮罩里的倍率 100–300%（遮罩不动，只有图变大） |
| 取景 | 在预览里直接拖图 / 滚轮缩放 / 双击复位；「复位」回到居中不缩放 |
| 标题字号 / 整版字号 | 80–140% / 70–150% |
| 对齐 | 自动 / 左 / 中 / 右 |
| 字段列数 | 自动 / 1 / 2 |
| 内容 | 别名、八个正文块（勾选 + 上下移动改顺序）、署名；封面单独开关 |
| 署名 | 默认 `OC Studio`，可清空 |

**「只导出一部分组件」就是在这里关掉**：关掉的块不渲染、后面的块自动上移，
版式不会给空块留占位。八个正文块的顺序 = 列表里的顺序，`PosterFlow` 按此渲染。

**海报的纸与墨是固定的**（`bg-paper-fixed` / `bg-ink-fixed` / `text-ink-fixed` /
`text-paper-fixed`，令牌见 `globals.css`）：海报是成品图，导出的那一张不该随界面亮暗变化
—— 纸色永远是纸白、夜色永远是墨底。版式里**不要**再用 `bg-paper` / `text-ink` 这类界面令牌：
它们在暗色主题下整体翻转，夜色会变成一张白纸、正文也全糊在一起。

**封面取景**（`poster/cover-frame.ts` 是几何唯一源）：

- 模型只有三个数 —— `coverZoom`（1–3）、`coverX` / `coverY`（0–100，等价于 CSS `object-position`）。
  落地成 `object-fit: cover` + `object-position` + 尺寸倍率，导出时 `html-to-image` 拿到同一份取值，
  预览与 PNG 不会对不上。
- 拖动是 **1:1 跟手**的：把「框比图小多少」当分母，拖 N 画布像素就挪 `N / 余量 × 100%`。
  某条轴没有余量（图已经严丝合缝）时那条轴拖不动 —— 先放大再拖，符合直觉。
- 双击 = 复位（居中、不缩放）。取景只在预览侧开启（`PosterCanvas` 传了 `onCoverAdjust` 才接线），
  导出用的是同一个组件但不接这个回调，所以 PNG 里不会留交互态。
- 槽位自己决定定位：满幅封面传 `absolute inset-0`，内联槽位只给尺寸。`PosterCover` **只在槽位没要求
  绝对定位时**才补 `relative` —— Tailwind 里 `.relative` 排在 `.absolute` 之后，两个类同时写就是
  `relative` 生效，满幅封面会掉回文档流、把标题和正文整块挤出画布（2026-11-05 夜色「全是白的」就是这个）。

> 参考 Simple_Cover 的调参思路（`docs/封面卡.md` §3）：参数都有范围、默认值与实时预览。
> 海报不做任意拖拽定位 —— 版式是完整构图，用户调的是**位置档位、封面大小、取景、对齐、列数、顺序**，
> 而不是把每个块拖到任意坐标。唯一能「自由拖」的是图片在遮罩里的取景，因为那块本来就是裁切，不是排版。

### 2.4 预览与导出

- 预览：`PosterCanvas` 以真实 1080 宽渲染，外层 `translate(-50%,-50%) scale()` 适配容器。
- 导出：同一组件在屏幕外按原尺寸渲染，`html-to-image` 的 `toPng`（`pixelRatio: 2`）→ 2160 宽 PNG。
- 基准字号 **24px**（`POSTER_BASE_FONT_SIZE`）：1080 宽海报上正文仍读得清；16px 缩到 40% 预览只剩 6px。
- 海报不滚动：超出画布的内容由版式自己裁（正文用 line-clamp），这是既定行为。

## 3. 静态网站（`site`）

- 左侧 iframe 预览，右侧版式 / 站点标题 / 分区 / 纸色 / 预设。
- 预览与导出调同一个 `buildSite()`；分区开关只在 `applySiteSections()` 里过滤一次。
- 图像预览始终用内联 data URI（看得见真图）；导出时才按「内联图片」开关决定是否内联。
- 单文件 `index.html`：内容、样式、脚本、图片全在里面，hash 路由可用。

### 三套版式（`lib/export/site/templates.ts`）

| id | 名字 | 外壳 | 首页 | 观感 |
|---|---|---|---|---|
| `book` | 书斋 | 侧栏 | 3:1 横幅 | 纸书：衬线站名、侧栏呼吸、列表 860 / 正文 720 |
| `archive` | 档案 | 顶栏 | 2.4:1 横幅 | 编号导航、等宽元数据、980 正文列、方角 |
| `gallery` | 画廊 | 顶栏 | 62vh 满幅 | 作品集：大标题压封面下缘、3/2/1 列卡片 |

- 外壳只有两种：`sidebar` / `topbar`；`build.ts` 按 `template.shell` 输出，
  `body[data-template="…"]` + 追加 CSS（排在基础样式之后、固定纸色之前）。
- 纸色：当前纸色 / 纸白 / 夜色 / 跟随读者系统。

## 4. 文档（`document`）

- 三个出口：**Word `.docx`**（默认）/ Markdown / TXT；左预览是**排好版的 A4 文档页**，不是源码。
- 一份模型喂三处：`lib/export/document.ts` 的 `buildDocumentModel()` 出 `DocumentModel`
  （标题 + 分区 + 条目 + 字段 + 正文 HTML/纯文本），预览画它，`renderMarkdown` / `renderTxt` /
  `buildDocumentDocx` 各自序列化它。**没有第二份生成逻辑**，所以预览与导出不会漂移。
- 正文走 `lib/export/site/render`（静态站同一套）：词条正文可能是 Tiptap JSON、早期 HTML 片段或纯文本，
  三种形态都在那里收口。旧版把正文当字符串直接拼进 `.md`，于是 `.md` 里会出现 `<p></p>` 这种噪声。
- 分区：角色 / 事件 / 国家 / 词条，四个可分别关掉；关掉的分区既不进预览也不进文件，计数仍显示。
- Word：`lib/export/document-docx.ts` 自己拼 WordprocessingML（ZIP 用 `lib/zip.ts`，不引第三方）。
  只做结构（标题 / 分区 Heading1 / 条目 Heading2 / 字段加粗），字体与页边距交给 Word。
- 日期按本地日历（不用 `toISOString()`，东八区凌晨会少一天）。
- 预览排版在 `globals.css` 的 `.oc-doc-prose`（纸面字号 12.5px / 1.85 行距，对齐 Word 的 A4 正文）。
- **预览组件是共用的**：`components/shared/document/PagePreview` 只认中性模型 `PageDoc`
  （`lib/export/page`：分区 → 条目 → 字段 + 正文），导出中心与**小说导出对话框**都用它；
  小说侧只多一个映射（`features/novel/preview-doc.ts#novelPageDoc`）。共用的是**预览**，
  三个格式仍各自从自己的源模型序列化 —— 只有那张「纸」需要长得一样。

## 5. 关系图（`graph`）

- 只出 PNG：`features/relations/export-graph.ts#renderRelationGraphCanvas` 按节点坐标**离线重绘**，
  不是屏幕截图 —— 视口怎么滚、缩放到多少都不影响输出（画布自己按内容包围盒 + 留白算尺寸，倍率上限 2×、最长边 4096）。
- 预览就是刚画出来的那张位图（`canvas.toDataURL()`），改标题 / 线型会重画；线型写回
  `settings.edgeStyle`（和关系图页面里的那个开关是同一个值，改哪边都一样）。
- 页面里的入口也走这里：关系图右上「更多 › 导出图片…」打开的就是本页签，不再自己弹一个保存框。
- 只收「图里有的东西」：`buildGraphData()` 的规则不变（没有引用的分类条目、小说 / 地图笔记都不进图）。

## 7. 预设

- 文件：`.ocstudio/exports.json`，`version: 2`。
  - `poster`：海报预设（`PosterOptions`）
  - `site`：网站预设（标题 / 分区 / 纸色 / 内联图片 / 版式）
  - `image`：旧版图片预设，只读保留（v1 数据不丢）
- 浏览器 / Mock 退化为 `localStorage` 的 `oc-export-presets`。
- 默认预设指针：`defaultPosterPresetId` / `defaultSitePresetId`，存应用设置。
- 内置海报预设：经典角色卡 / 夜色竖版 / 档案页（可应用、可设默认、不可删）。
- 会话选项：海报 `oc-poster-export`、网站 `oc-site-export`。

## 10. 不做的

- 多文件静态站（`index.html` + 资源目录）——当前始终单文件。
- EPUB / PDF 排版。
- 海报任意坐标拖拽（见 §2.3 的说明）。
- 用户自定义版式 / CSS（走插件系统后再谈）。
