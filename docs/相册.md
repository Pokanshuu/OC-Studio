## 1. 已经想清楚的部分

### 1.1 槽位决定分组

相册的分组不应该是自由分类，而是**图片槽位**（见 `docs/模板.md` §4.1）：封面 / 头像 / 立绘 / 图片 / 画廊，每个槽位一个抽屉，外加「正文图片」。

理由：槽位本来就是语义（比例、裁剪、谁在别处取它都不同），再叠一套用户自定义分类，就是第二个分类系统。

### 1.2 目标形态（组件原子化，不是"是否复用"）

```
PhotoItem / PhotoSource（适配器）
  ├─ PhotoCard          单张卡片
  ├─ PhotoGrid          网格
  ├─ PhotoStrip         滑动条（替代 slider）
  ├─ PhotoViewer        全屏（入参改成 PhotoItem[]）
  ├─ PhotoPicker        全局选择器（唯一选图面）
  └─ PhotoField         字段绑定（图片槽位控件）
```

`ImageGallery` 与 `GlobalAlbum` 退化成**组合**，不再各写一套网格。

迁移顺序：**先抽组件，后换调用点**；保留现有 slider / grid / addTile / externalAdd / crop / 长按 / 筛选行为。
