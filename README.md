# OC Studio

一个本地优先的原创角色（OC）与世界观创作工作台。让创作更高效，工具退后，内容向前。

当前版本：**v0.1.0-alpha**（早期测试版，功能不完整，可能有 Bug）

---

## 主要功能

- **事件模块**：创建、编辑、排序事件，支持时间、地点、相关角色/国家，AI 概括摘要
- **角色模块**：完整的角色信息卡（基本信息、人物简介、人物生平、相册），支持相关人物关联
- **国家模块**：国家/地区信息管理（政治制度、地理环境、人文风貌），关联角色与事件
- **世界观百科**：树状词条结构，一体化编辑器，支持 `[[` 词条内链和 `@` 引用
- **时间线**：年/十年/百年聚合视图，拖拽调整事件时间，缩放浏览
- **编辑器**：富文本编辑，支持 Markdown 快捷输入、斜杠命令、块拖拽排序、表格、待办列表
- **全局搜索**：`Ctrl+K` / `Cmd+K` 唤起，跨模块搜索角色、事件、国家、词条
- **数据导入/导出**：JSON 格式（`.ocbak`），支持数据备份与迁移
- **桌面应用**：Windows 原生体验（Tauri 打包），无边框窗口

---

## 技术栈

- **前端**：Next.js 14 (App Router) + TypeScript + Tailwind CSS + shadcn/ui
- **编辑器**：Tiptap (ProseMirror)
- **本地数据库**：Dexie.js (IndexedDB)
- **桌面打包**：Tauri v2
- **图标**：lucide-react

---

## 快速开始

### 在线 Web 版（开发模式）

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`

### 桌面应用

```bash
npm run build
npx tauri build
```

生成的 `.exe` / `.msi` 在 `src-tauri/target/release/bundle/` 目录下。
